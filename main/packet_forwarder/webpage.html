Formato
Codificação

mqtts:// é criptografado com TLS (porta 8883). mqtt:// é sem criptografia (porta 1883).

Certificados TLS

Sem CA enviada, o gateway confia nas autoridades públicas (Let's Encrypt e outras). Envie a CA se o broker usa certificado próprio. Certificado e chave do cliente só são necessários para TLS mútuo. Cada envio é aplicado na hora.

Acesso

Usuário e senha pedidos ao abrir esta página.

Mínimo de 6 caracteres. Depois de salvar, o navegador pede o novo login. Esqueceu? No console serial: web_auth --reset (volta para admin / lorawan101).

Manutenção
